    Two ways to fill this drive

    1. Drop files here (fastest). Drag anything onto this page — or press “Upload files”. Files are stored in this browser’s IndexedDB, they stay available on your next visit, and they are searchable, previewable and downloadable exactly like repo files.
    2. Commit to the repo (permanent, shared). Add your file under files/<category>/ in the Storage repo, then list it in js/manifest.js (or run npm run build:manifest to generate it automatically). GitHub Pages publishes it and everyone with the link gets the same library.

    Tip: press / to search, Esc to close a preview, g then a number to jump between categories.
